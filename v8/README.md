# v8 - ASCII Art

**Size:** 1054 bytes

Retro ASCII art banner with cyberpunk styling.

## Features

- ASCII art header in `<pre>` tag
- Cyan/magenta neon color scheme
- Glow effects via text-shadow
- Dark background
- Minimal navigation

## Design

Combines ASCII art nostalgia with modern CSS glow effects. The pre-formatted banner provides visual impact while staying compact. Neon colors against dark background for that retro-futuristic vibe.
