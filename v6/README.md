# v6 - Brutalist

**Size:** 1232 bytes

Raw, honest, functional design with no decorative elements.

## Features

- Bold serif/sans-serif typography
- High contrast black and white
- Yellow highlight links
- Square bullet lists
- Dashed horizontal rules
- Blocky button styling

## Design

Anti-design philosophy. No gradients, no shadows, no rounded corners. Just pure content with stark visual hierarchy. Links use yellow highlight, buttons invert on hover.
