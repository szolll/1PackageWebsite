# v5 - Retro Terminal

**Size:** 1281 bytes

A DOS/terminal aesthetic with green-on-black styling.

## Features

- Monospace font throughout
- Blinking cursor animation
- Command prompt styling (`> cat`, `> ls`)
- Bracket-style links `[link]`
- Scanline-inspired border
- Green phosphor glow effect

## Design

Classic terminal look with `#0f0` green on `#0c0c0c` black. Uses CSS animations for the blinking cursor. Links invert on hover for that authentic terminal feel.
