# v7 - Neumorphism

**Size:** 1167 bytes

Soft UI design with extruded and inset shadows.

## Features

- Soft shadow extrusion effect
- Pressed/inset button states
- Muted color palette
- Rounded corners throughout
- Subtle depth without harsh contrasts

## Design

Uses dual box-shadows (light and dark) on a mid-tone background to create the signature "soft UI" look. Buttons appear to press inward on hover/active states.
