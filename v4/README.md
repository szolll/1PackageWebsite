# v4 - Neon Cyberpunk

**Size:** 1400 bytes

A visually striking animated design with modern CSS effects.

## Features

- Animated gradient background (shifts continuously)
- Glowing gradient text (magenta to cyan)
- Glassmorphism card with backdrop blur
- Hover animations (scale + glow)
- Responsive typography with `clamp()`
- Button hover fill effect

## Design

Dark cyberpunk aesthetic. All animations are pure CSS with no JavaScript. Uses `@keyframes` for smooth infinite animations and `backdrop-filter` for glass effect.
