Getting Started

Installation

Install 1Package with a single command. No config required out of the box.

npm install 1package
Usage

Basic Setup

Import and initialize. Everything is available from the root export.

import pkg from '1package'

pkg.init({ mode: 'minimal' })
Configuration

Options

All options are optional. Defaults are sane and production-ready.

{
  mode: 'minimal' | 'full',  // default: minimal
  cache: true,               // default: true
  debug: false               // default: false
}
FAQ

Does it work with TypeScript?

Yes. Types are bundled. No @types package needed.
